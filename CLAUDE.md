# orio-ui

Nuxt module exposing a Vue 3 component library. Auto-import prefix: `Orio` →
`<orio-button>`, `<orio-canvas-stage>`, etc.

## Component routing index

Source under `src/runtime/components/` and `src/runtime/composables/`.
Public docs under `docs/components/` and `docs/composables/`.

Agent docs live in `agents/`, a mirror of the source tree — one `.md` per
entry, for agents only:

- `Modal.vue` → `agents/components/Modal.md`
- `date/Picker.vue` → `agents/components/date/Picker.md`
- `Canvas/` → `agents/components/Canvas.md` (folder components with several
  docs keep a directory: `agents/components/NumberInput/index.md`)
- `useFilter` → `agents/composables/useFilter.md`
- experiments → `agents/experiments/<name>.md`

Read only the one you need. Entries marked **Read the agent doc first.**
document non-trivial invariants/gotchas; read them before touching that
component. The block below is generated by `scripts/generate-routing.mjs`
from the frontmatter of those docs; do not edit by hand.

### Composables
- `useApi` — thin typed wrapper around ofetch's `$fetch` for GET/POST/PUT/DELETE/PATCH requests.
- `useControlSize` — provide/inject `ControlSize` (xs/sm/md/lg/xl) and read a CSS-var token bag for the active size. **Read the agent doc first.**
- `useDecimalFormatter` — parse numeric strings (US or EU separator) and format via Intl.NumberFormat with locale defaults. **Read the agent doc first.**
- `useFilter` — named filter group with v-bind bags, $-helpers, $active chips, $clearAll, optional URL sync via lazy import. **Read the agent doc first.**
- `useFuzzySearch` — typed Fuse.js wrapper that returns a computed list of matched items (strings or objects).
- `useInertia` — post-drag momentum loop that calls a tick callback with decaying velocity each frame. **Read the agent doc first.**
- `useListKeyboard` — arrow / Home / End / Enter / Space / Esc handling for a flat indexable list with auto scroll-into-view. **Read the agent doc first.**
- `useModal` — returns a `modalProps` bag (show, origin, update handler) plus `openModal(event?)` that derives origin from a click target. **Read the agent doc first.**
- `usePinchZoom` — touch-only pinch handler that tracks up to 2 pointers and exposes scale factor, midpoint, and midpoint delta. **Read the agent doc first.**
- `usePressAndHold` — fires a callback once immediately, then repeats every 50 ms after a 500 ms hold. **Read the agent doc first.**
- `useRovingGrid` — 2D arrow-key roving focus for grid-like UIs; handles arrows, Home/End, PageUp/Down, Enter/Space, and edge-overflow callbacks. **Read the agent doc first.**
- `useSound` — low-latency Web Audio playback with a shared module-level AudioContext and per-URL buffer cache. **Read the agent doc first.**
- `useTheme` — cookie-backed theme and mode (light/dark) accessor that writes `data-theme` and `data-mode` on `<html>`. **Read the agent doc first.**
- `useUrlSync` — bidirectional sync between a reactive object and URL query params; SSR-safe initial read, client-only writes. **Read the agent doc first.**
- `useValidation` — declarative rule-based form validation with reactive errors keyed by field id and auto scroll-to-first-error. **Read the agent doc first.**

## Writing examples

**Every example must be code that actually runs in this repo.** Never invent a
snippet from memory of the API.

- Write the example as a real demo first — a block in `docs/**/*.md` (which the
  VitePress app renders live) or a test in `tests/` — confirm it works, then
  copy it verbatim into the agent doc or prose.
- When an example already exists, quote the existing one instead of writing a
  parallel version. The `docs/**` demo is the source of truth; the agent doc's
  quick reference mirrors it, adjusted only for the consumer import path.
- Say where an example came from when it is not obvious (`# from
  docs/experiments/select.md`), so the next edit updates both.
- An example that was never executed is a bug report waiting to happen: props
  that do not exist, slots with the wrong name, imports from the wrong path.

## Agents

Narrow subagents live in `.claude/agents/`:

- `component-finder` (haiku, read-only) — resolves vague requests to source path + agent-doc path + relevant composable docs. No reads beyond locating.
- `component-worker` (inherit) — picks the matching component, reads its agent doc and source, then implements (e.g. wires the component into a consumer app).
- `use-filter-onboarder` (opus) — integrates `useFilter` end-to-end: defines the group, binds pickers, builds chip bars, wires URL sync. Triggered by "add filters", "wire up useFilter", "filter bar with chips".
- `usage-auditor` (sonnet, read-only) — audits a component/composable's `agents/` doc for drift after its source changes. Dispatched automatically via a PostToolUse hook (`scripts/hooks/usage-audit-reminder.mjs`); reports findings, caller applies fixes.
Routing/component agents hold the full component list in their prompt prefix for cache-friendly reuse. The onboarder holds the `useFilter` API + canonical patterns in its prefix for the same reason.
